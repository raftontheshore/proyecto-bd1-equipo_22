# Alcance del Sistema

## ¿Qué funciones cubrirá el sistema?

- Gestión de productos (alta, baja y modificación de videojuegos, consolas y accesorios).
- Gestión de categorías del catálogo.
- Panel administrativo para el personal del negocio.
- Exploración y filtrado del catálogo por parte de los clientes.
- Carrito de compras y proceso de checkout con validación de datos.
- Registro y control de ventas.
- Control de stock e inventario.
- Manejo de imágenes de producto (carga de archivo o por URL).
- Registro de consultas/contacto de clientes.
- Generación de reportes estadísticos de ventas para la toma de decisiones.

## ¿Qué funciones no cubrirá el sistema?

- No se gestionarán proveedores.
- No se incluirá integración con medios de pago externos (pasarelas de pago reales).
- No se contemplará logística de envíos ni seguimiento de pedidos.
- No se administrará más de un local o sucursal (alcance limitado a un único punto de venta).
- No se incluirá un programa de fidelización o puntos para clientes.
